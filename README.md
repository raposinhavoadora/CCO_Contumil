# CCO Contumil

A browser signalling simulator for the Centro de Comando Operacional de Contumil: the Minho, Douro and Guimarães lines, the Braga branch and the Leixões goods line, run from Porto.

**Play it:** https://raposinhavoadora.github.io/CCO_Contumil/

## What you do

- Set routes signal to signal, plan crossings on single track, and keep trains to time.
- Pick a shift: Tuesday morning peak (05:30–10:00), quiet Saturday morning (07:00–11:30) or busy Friday evening (16:30–21:00).
- Choose which desks you control; the rest run on ARS (automatic route setting).
- Handle loco-hauled specials that reverse (the locomotive runs round its train), freight to the goods terminals (Cimpor, Leandro, Tadim, S. Martinho do Campo, Darque, Godim), and failures that need the Socorro rescue unit from Contumil.
- Route Devesas ⇄ Leixões freight and the Ovar ⇄ Leça do Balio urbanos through the single-track underpass between Campanhã and Contumil.

## Files

`index.html` is the whole simulator: plain HTML, CSS and JavaScript, no build step. Open it in a browser to run it locally.
